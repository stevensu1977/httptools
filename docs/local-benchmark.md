# 本地吞吐验证

日期：2026-10-26。环境可见 8 个逻辑 CPU，型号为 Intel Xeon 6975P-C。
这是当前开发环境，**不是 m5.2xlarge 的实测结果**。

构建：Rust 1.93.1，`cargo build --release --bin batchbench --example mock_server --locked`。
压测客户端与模拟服务运行在同一台机器，通过 HTTP 回环通信。
每个场景发送窗口为 10 秒，使用默认字段模板；认证为测试凭据。
模拟服务读取完整请求体、复用连接，返回 `200 {"ok":true}`。

| Batch 大小 | 目标 HTTP RPS | 并发 | 模拟延迟 | 成功请求数 | 成功 HTTP RPS | 事件/秒 | p99 延迟 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 随机 1–10 | 10,000 | 512 | 0 ms | 99,983 | 9,996.30 | 54,904.72 | 0.181 ms |
| 固定 10 | 12,000 | 512 | 0 ms | 119,990 | 11,997.38 | 119,973.78 | 0.210 ms |
| 随机 1–10 | 10,000 | 1,024 | 50 ms | 99,993 | 9,947.97 | 54,693.77 | 52.175 ms |

所有场景 HTTP/传输失败数均为 0。事件数按实际生成的 batch 大小累计。
RPS 的分母包含最后一批在途请求完成的时间，因此 50 ms 场景的整体 RPS 更低。

这些结果说明当前开发环境下模板生成和 HTTP 请求执行可以达到约 12,000 POST/秒；
该测试不包含 TLS、远程网络、API Gateway 或真实业务处理，不能据此保证 m5.2xlarge
访问真实 HTTPS 接口达到相同吞吐。没有对用户的 API Gateway 地址执行这些负载测试。
